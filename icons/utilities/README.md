# Original native-utility artwork candidates

`geometry.py` provides editable stats/two-display-brightness/overflow specifications
and an explicit lazy Blender 4+ data adapter. It never imports the destructive
Trash generator, changes the active scene, renders, saves or deletes existing data.
The separately hideable backing reads only the existing Studio family contour;
original attribution stays with its unchanged source. Current opaque relief
materials are starting intent, not approval of glass appearance or family optics.

`symbols.py` authors 32 self-contained `currentColor` SVG candidates: eight states
at 16/20/24/32px. Small sizes have independently authored metrics. Unavailable
states use a dash, never fabricated zero measurements. These are original candidate
identities, not installed aliases, detected monitor counts or live readings.

```sh
python -B -m unittest discover -s icons/tests -p 'test_utility_*.py' -v
python -B icons/utilities/symbols.py --help
```

Only explicit `--export-candidates` creates a NEW source-local
`studio-utility-symbols.candidates` directory. Existing output, escaped/symlinked
ancestry and alternate output paths are refused. There is no installer or default
export. Failures can leave new partial owned output; nothing is destructively
cleaned up. Export assumes the owned directory is not concurrently redirected.

The GPT-Astra-requested isolated handoffs were source-reviewed and parent-integrated.
Routing is not independent provider attestation. The 27 tests cover specification,
XML, safety and a fake Blender adapter—not real Blender, rendered recognition,
recoloring, contrast, fractional scales, widget accessibility or desktop behavior.
Approved dock/Trash files and active theme lookups are unchanged. Actual editable
scene exports, optical review and native integration remain open.
